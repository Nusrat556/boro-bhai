# BORO BHAI

BORO BHAI is a personal AI agent project built progressively in Python with Ollama and local open-source models.

## Current stage

This repository is in its initial foundation stage. We are setting up the project structure, virtual environment, and repository hygiene before building the agent itself.

## Project goals

- understand how an AI agent works from the inside
- use a local LLM through Ollama
- add tools for calculations, file reading, and data analysis
- add memory and document processing
- later add web research, job analysis, and learning recommendations

## Minimal structure

- app/
- tools/
- memory/
- data/
- reports/
- tests/

## Environment

We will use:

- Python 3.13
- pip
- Git
- virtual environment (.venv)
- Ollama + local model

## Development approach

We are building this in small stages. This helps us understand the underlying mechanics before introducing frameworks or advanced tooling.
